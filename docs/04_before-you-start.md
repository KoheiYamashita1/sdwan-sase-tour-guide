# 始める前の準備

## 受け取るもの

| もの | 受け取り方 | 使うところ |
|---|---|---|
| 体験ポータルの招待メール（仮のパスワード） | メールで届く | ポータルのログイン |
| SD-WAN Manager の URL、利用者名、パスワード | 会場の担当者から | BASE-01〜05、SSE-01 |
| 席の URL、Duo の利用者とパスワード、Windows の利用者とパスワード | ポータルのトップページの「あなたの席」に出る | SSE-03、SSE-02 |

資格情報は書き写したり、人に見せたり、AI エージェントとの会話に貼ったりしないでください。

## 手元に用意するもの

- PC とブラウザ（Chrome または Edge）。手元の PC にソフトを入れる必要はありません
- 画面を 2 つ並べられると楽です（ポータルの手順と、SD-WAN Manager や席の画面）

## ログインの流れ

### 1. 体験ポータル

1. 招待メールにある https://showcase.cpocjp.com を開きます
2. メールアドレスと仮のパスワードでログインし、初回にパスワードを決めます
3. トップページにツアーの一覧が出ることを確かめます

### 2. SD-WAN Manager

1. 会場の担当者から受け取った URL を開きます
2. 証明書の警告が出たら、担当者の案内に従って先に進みます（自己署名の証明書です）
3. 受け取った利用者名とパスワードでログインし、Dashboard が出ることを確かめます

パスワードは変えないでください。体験者みんなとポータルの live の確認が同じ利用者を使っています。

### 3. 席（SSE-03 の前に）

ポータルのトップページの「あなたの席」で「席をもらう」を押します。入り方は SSE-03 のツアーで 1 つずつ案内します。

- 「いま空いている席がありません」と出たら、しばらくしてからもう一度押します
- 「まだ用意していません」と出る項目があれば、会場の担当者に知らせます

## 確かめること

- [ ] ポータルにログインでき、ツアーの一覧が見える
- [ ] SD-WAN Manager にログインでき、Dashboard が見える
