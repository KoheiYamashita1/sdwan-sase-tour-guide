# 全体像

## 何を体験するか

Cisco の 3 つの製品をつないだ実機のショーケースを、体験ポータルの「ツアー」に沿って触って確かめます。

| 製品 | 役割 | 体験者の触り方 |
|---|---|---|
| Cisco Catalyst SD-WAN（SD-WAN Manager） | 拠点のルータを WAN でつなぎ、設定と監視をまとめて行う | 読み取り専用の利用者でログインし、画面を見る |
| Cisco Secure Access（CSA） | クラウドのセキュリティ。拠点のインターネット向けの通信を検査し、ZTNA で社内の端末に入れる | 管理画面には入らない。ZTNA の利用者側の入口から、自分の席の Windows に入る |
| Security Cloud Control（SCC） | セキュリティ製品を組織ごとにまとめて見る管理画面 | 入らない。ツアーの画面のサンプルで見る |

ツアーは全部で 9 本です。

| 区分 | ツアー | 主に見るもの |
|---|---|---|
| SD-WAN の基本 | BASE-01〜05 | 設定の組み立て、オーバーレイの状態、権限、通信の可視化、AI Assistant と Analytics |
| SCC | SCC-01 | 組織と製品を 1 つの画面で見る |
| SSE（Secure Access） | SSE-01〜03 | SD-WAN から CSA への自動トンネル、ZTNA で席に入る、Web のカテゴリ制御 |

## 体験ポータルとツアーの仕組み

体験者は、招待メールで届く体験ポータル（https://showcase.cpocjp.com）にログインし、ツアーを選んで進めます。

- ツアーは手順に分かれ、手順ごとに「やること」「確認すること」が書いてあります
- 手順の終わりには確認があります。確認には 3 種類あります

  | 確認 | 体験者がすること |
  |---|---|
  | 自己申告 | 画面で確かめたら「できた」を押す |
  | クイズ | 選択肢から 1 つ選んで答える。正解なら手順がクリアになり、不正解なら解説が出る |
  | live（実機の確認） | 「確認する」を押すと、ポータルが製品の API で実機の状態を確かめる |

- 前提のツアーがあるツアーは、前提をクリアするまで「前提のツアーが未クリア」と出て進められません
- すべての手順をクリアするとツアーが「クリア」になり、「資料庫」からそのツアーの PoC / PoV 確認項目シートをダウンロードできます

## 体験者ができること、できないこと

| できること | できないこと |
|---|---|
| SD-WAN Manager にログインし、機器の状態や設定の中身を見る | 設定の保存、機器へのデプロイ、利用者の管理 |
| ポータルで席（site-172 の Windows）をもらい、ブラウザから RDP で入る | 席で管理者の権限が要る操作、パスワードの変更 |
| 席のブラウザで Web を開き、CSA で止まることを確かめる | CSA と SCC の管理画面に入る |

SD-WAN Manager の利用者は、体験者みんなで使う共有の利用者です。パスワードは変えないでください。
