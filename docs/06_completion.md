# 完了の条件と、終わったあとにすること

## 完了の条件

- [ ] ポータルのツアーの一覧で、11 本（BASE-01〜05、SCC-01、SSE-01〜03、SSE-06、CCC-01）がすべて「クリア」になっている
- [ ] 資料庫に、クリアしたツアーの PoC / PoV 確認項目シートが並び、ダウンロードできた
- [ ] ポータルのアンケート（5 問）に答え、資料庫から修了の資料（PoC / PoV の計画書）をダウンロードできた

短く回したとき（[アジェンダ](02_agenda.md)）は、選んだツアーがすべて「クリア」になっていれば完了です。アンケートは 11 本をクリアしたときだけ出ます。

## アンケート

11 本をクリアすると、ポータルのトップページと資料庫にアンケートの案内が出ます。

| 番号 | 質問 | 形式 |
|---|---|---|
| 1 | 全体の満足度 | 5 段階、必須 |
| 2 | 一番役に立ったツアー | 11 本から 1 つ、必須 |
| 3 | 自社で検討や PoC をしたいか | 選択、必須 |
| 4 | 分かりにくかった所、詰まった所 | ツアーを選んで記述、任意 |
| 5 | 足してほしい内容、改善の案 | 記述、任意 |

- 回答は、メールアドレスと結び付けずに残ります
- 4 と 5 の記述は、「匿名で公開の GitHub に載せてよい」に同意したときだけ、このリポジトリの Issue に載ります。会社名、お名前、メールアドレス、パスワードのようなものがある記述は、同意があっても載りません
- GitHub のアカウントがあれば、このリポジトリの Issue のフォームからも送れます（公開されます）

## 終わったあとにすること

1. 席の Windows からサインアウトし、席の画面のタブを閉じる
2. SD-WAN Manager からログアウトする
3. ポータルからログアウトする（ブラウザを閉じる）
4. 書き留めた資格情報があれば消す。AI エージェントとの会話に資格情報が残っていないかを見る

体験者のアカウント、席、進み具合は、体験会のあとに管理者が消します。体験者が消す必要はありません。

## 振り返り

AI エージェントは、最後に次のことを短くまとめて利用者に伝えます。

- クリアしたツアー
- SD-WAN の基本（設定の組み立て、オーバーレイ、権限、可視化）で見たこと
- SASE（SIA、ZTNA、Web のカテゴリ制御、VRF ごとのポリシー）で見たこと
- CCC の AI に聞いて確かめたこと
- 途中で詰まったところ（アンケートの 4 を書くときの手がかりにする。記述は利用者が自分で書く）
