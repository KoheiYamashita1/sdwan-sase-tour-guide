# SSE-03 クライアントレス ZTNA で拠点の端末に入る

- 時間: 15 分 / 前提: なし / 使う画面: ポータル、Duo のログイン、席の Windows（ブラウザの中の RDP）

## 目的

Cisco Secure Access（CSA）のクライアントレス ZTNA で、手元のブラウザから site-172 の席の Windows に RDP で入ります。
手元の PC にソフトは入れません。ここで覚えた入り方を SSE-02 でも使います。

## 流れ

| 手順 | やること | 確認すること | 確認 |
|---|---|---|---|
| 1 自分の席 | ポータルのトップの「あなたの席」を見る。席が無ければ「席をもらう」 | 席の名前とアドレス、その下に「席の URL を開く:」（URL のリンク）「Duo でログインする:」「Windows にログインする:」の 3 行 | 自己申告 |
| 2 席の URL を開く | 「席の URL を開く:」の横の URL のリンクを押す（新しいタブ）。ポータルのタブは残す | Duo の「シングル サインオン」の画面が出る | 自己申告 |
| 3 Duo でログイン | Duo の利用者（`seat-172-N@...` の形）とパスワードを入れる。ブラウザの更新を勧める画面は「今はスキップ」 | 2 要素認証を聞かれずに先に進む | 自己申告 |
| 4 席の Windows に入る | 「Connect to seat-172-N」の画面で、キーボードは English (US) のまま、Username `visitor` と Windows のパスワードで Connect。デスクトップで `cmd` を開き `whoami` と `ipconfig` | `whoami` が `seat-172-N\visitor`、IPv4 が自分の席のアドレス | 自己申告 |
| 5 席ごとに分ける理由 | 説明を読む（Duo の利用者、CSA の Private Resource とルールが席ごと） | — | クイズ（席ごとに分けている理由） |
| 6 ZTNA と VPN | 説明を読む | — | クイズ（リモートアクセス VPN との違い） |
| 7 席から出る | 席の Windows でサインアウトし、席のタブを閉じる | 席の画面のタブが残っていない | 自己申告 |

## 補足

- 資格情報はポータルの「あなたの席」を見ながら自分で入力します。Windows のパスワードは英字と数字だけなので、英語の配列でそのまま打てます
- 最初のログインはデスクトップが出るまで 1 分ほどかかることがあります
- 1 回のセッションは最長 30 分です。切れたら「席の URL を開く」から入り直します
- ほかの席の URL を開くと、Duo のログインのあとに「Access Denied」が出ます。これは正しい動きです
- 続けて SSE-01、SSE-02 に進むなら、手順 7 でサインアウトしても、SSE-02 で同じ方法で入り直せます
