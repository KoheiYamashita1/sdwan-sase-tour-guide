# BASE-03 役割ごとのアクセス制御（読み取り専用の利用者）

- 時間: 10 分 / 前提: なし / 使う画面: SD-WAN Manager

## 目的

SD-WAN Manager では、利用者をユーザーグループに入れ、グループに機能ごとの Read / Write を付けます。
配られた共有の利用者で、見られることと変えられないことを確かめます。

## 流れ

| 手順 | やること | 確認すること | 確認 |
|---|---|---|---|
| 1 ログイン | 配られた利用者で SD-WAN Manager にログインする | Dashboard が出る | 自己申告 |
| 2 ユーザーグループ | 説明を読む（既定のグループ netadmin、operator など） | — | クイズ（見るだけの利用者のグループ） |
| 3 Read と Write | 説明を読む | — | クイズ（Write を付けたときの Read） |
| 4 見られること | **Monitor** > **Devices** で 3 台を見る。**Configuration Groups** で `SHOW-AWS` を開き、Feature Profile の中身を見る | 状態も設定も見られる | 自己申告 |
| 5 変えられないこと | `SHOW-AWS` の Feature Profile と Deploy のボタンを探す（押さない、値を変えない） | 保存もデプロイもできない | 自己申告 |
| 6 利用者を管理できる人 | **Administration** に **Users and Access** があるかを見る（何も変えない） | 自分のメニューには出ない | クイズ（利用者を管理できるのは誰か） |

## 補足

- パスワードは変えないでください（共有の利用者です）
- `SHOW-AWS` は AWS の 3 拠点に実際に配っている構成グループです。保存やデプロイができそうに見えたら止めて、会場の担当者に知らせます
