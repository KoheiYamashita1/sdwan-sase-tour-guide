# SSE-02 Web 閲覧のカテゴリ制御とブロック画面、ログでの確認

- 時間: 15 分 / 前提: SSE-01 と SSE-03 / 使う画面: ポータル、席の Windows の Edge

## 目的

site-172 の席のブラウザで、止めるカテゴリ（Adult、Gambling）のサイトを開き、CSA で止まることを確かめます。
最後に、ポータルが CSA のログを API で読み、あなたの席の通信が止まったことを確かめます。

## 流れ

| 手順 | やること | 確認すること | 確認 |
|---|---|---|---|
| 1 自分の席 | ポータルの「あなたの席」を見る | 席の名前とアドレス（覚えておく） | 自己申告 |
| 2 席に入る | SSE-03 と同じ方法で席に入り、Microsoft Edge を開く | 席のデスクトップと Edge | 自己申告 |
| 3 許可するサイト | **席の Edge で** `https://www.cisco.com/` を開く | Cisco のページが出る | 自己申告 |
| 4 止めるサイト（HTTP） | **席の Edge で** `http://exampleadultsite.com` を開く（`http://` で打つ） | Secure Access のブロック画面 | 自己申告 |
| 5 止めるサイト（HTTPS） | **席の Edge で** `https://exampleadultsite.com` を開く（`https://` で打つ）。警告の先には進まない | ブロック画面ではなく証明書の警告 | クイズ（警告になる理由） |
| 6 ポータルで確かめる | ポータルの「確認する」を押す | 「クリア」になる | live（直近 15 分の CSA のログに、席のアドレスの Blocked があるか） |
| 7 管理者の画面 | 説明を読む（CSA の Activity Search のサンプル） | — | クイズ（ポータルがどうやってあなたの通信を見分けるか） |

## 補足

- 手順 3〜5 は必ず**席の Edge**で行います。手元のブラウザの通信は CSA を通らないので止まりません
- `exampleadultsite.com` は Cisco が試験用に用意したサイトで、実在の成人向けのサイトではありません
- 手順 6 で「まだ確認できません」と出たら、数分待って押し直します。手順 4 から 15 分より長くたっていたら、手順 4 をもう一度してから押します。2 回続くと「できた（自己申告）」が出るので、ブロック画面を見ていれば押して進めます
- 「確認できませんでした」は API に問い合わせられなかったときです。ブロック画面を見ていれば自己申告に切り替えて進めます
- 1 つの席を同時に 2 人で使わないでください。ポータルは席のアドレスで本人の通信を見分けます
- 終わったら、席の Windows でサインアウトし、席のタブを閉じます
